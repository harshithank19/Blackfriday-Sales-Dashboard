## 📌 Overview

This dashboard dives into Black Friday transaction data to understand who buys what, how much they spend, and which product categories drive the most revenue — helping retailers make smarter inventory and marketing decisions.

---

## 📈 Dashboard Features

| Visual | Insight |
|--------|---------|
| Cards | Total purchases, unique customers, avg spend |
| Bar Charts | Product category-wise sales performance |
| Pie Charts | Sales by gender, age group, city category |
| Line Graphs | Purchase trends across demographics |
| Filters | Slice by gender, age, occupation, city |

---

## 🔍 Key Insights

- Male customers account for a significantly higher share of purchases
- Age group **26–35** is the highest spending demographic
- **Category 1** products dominate overall sales
- Customers from **City Category B** contribute the most purchases
- Single customers tend to spend more than married customers

## 🚀 How to Use

1. Download and install [Power BI Desktop](https://powerbi.microsoft.com/desktop/)
2. Clone this repository
3. Open `Black Friday BI Project.pbix` in Power BI Desktop
4. Use the filters to explore sales by demographics and categories
